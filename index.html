快速开始

三行代码开始调用

兼容 OpenAI SDK，已有的代码改两行就能跑。

Python · openai SDK
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.myagentlab.homes/v1"
)

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "你好！"}]
)
print(response.choices[0].message.content)

常见问题

什么是 AI API 中转站？

AI API 中转站（也称为 API 代理、API 聚合平台）是一种服务，它将 OpenAI、Anthropic、Google 等多家 AI 厂商的 API 接口整合到统一的入口。用户只需一个 API Key，就能调用所有大模型，无需分别注册每个平台。智体工坊 MyAgentLab 就是这样一个中转站，完全兼容 OpenAI API 格式，更换 Base URL 即可使用。

智体工坊的 API 兼容 OpenAI 格式吗？

完全兼容。智体工坊使用 OpenAI 兼容接口，支持 /v1/chat/completions、/v1/embeddings、/v1/images/generations 等标准端点。Python/Node.js 的 OpenAI SDK、LangChain、LlamaIndex、Dify、FastGPT、NextChat 等主流框架和工具均可直接使用，只需修改 API Base URL 和 API Key。

比直连 OpenAI / Claude 官方 API 便宜多少？

智体工坊的大模型 API 价格比直连官方最高便宜 50%-90%。例如 GPT-4o 官方价格 $5/百万 Token，通过中转站可节省大量费用。DeepSeek、Qwen、GLM 等国产模型价格更低。具体价格请参考定价表，按量计费，充值即用。

支持哪些编程语言和 SDK？

支持所有兼容 OpenAI API 的 SDK 和工具，包括：Python openai 库、Node.js openai 库、Go、Java、Rust、PHP、C# 等。同时也支持 LangChain、LlamaIndex、Dify、FastGPT、NextChat、ChatGPT-Next-Web、LobeChat、Open WebUI 等主流 AI 应用框架。

国内可以直接访问吗？需要翻墙吗？

可以。智体工坊提供国内优质线路直连，无需翻墙即可调用 GPT、Claude、Gemini 等海外大模型 API。平均响应延迟低于 100ms，比直连官方 API 更快。同时也支持 DeepSeek、Qwen、GLM 等国产模型。

如何获取 API Key？

注册智体工坊账号后，在控制台创建 API Key 即可使用。支持多 Key 管理、用量监控、速率限制等功能。充值后立即到账，按量计费，用多少付多少。

支持图像生成和语音模型吗？

支持。智体工坊不仅提供文本对话模型（GPT-4o、Claude、DeepSeek 等），还支持图像生成模型（DALL·E 3、Stable Diffusion、FLUX）、语音模型（Whisper 语音识别、TTS 语音合成）、以及多模态模型（GPT-4o Vision、Gemini Vision、GLM-4V）。

和 One API / New API 有什么区别？

智体工坊基于 New API 构建，但提供了更完善的中文界面、微信支付、更多模型接入、以及更好的国内线路优化。相比自建 One API / New API，使用智体工坊无需自己维护服务器和上游渠道。
